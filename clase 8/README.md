Pagina web de Fragancias Internacionales

Descripción:
Fragancias Internacionales es una pagina web desarrollada con React que consume una API de productos
La pagina permite ver perfumes, buscarlos por nombre, filtrarlos por género (Hombre, Mujer y Unisex) y agregar o quitar perfumes de una lista de favoritos.

Tecnologías utilizadas:
* React
* JavaScript
* CSS
* Vite
* API DummyJSON

Conceptos de React utilizados:
* useState
* useEffect
* Componentes
* Props
* Eventos y Handlers
* Renderizado condicional
* Destructuring
* Spread Operator
* map()
* filter()

Funcionalidades:

Buscador:
Permite buscar perfumes por nombre

Filtros:
Permite filtrar perfumes por:
* Todos
* Hombre
* Mujer
* Unisex

Favoritos:
Permite agregar y eliminar perfumes de una lista de favoritos

Consumo de API:
Los datos son obtenidos desde una API externa

API utilizada:
https://dummyjson.com/products
